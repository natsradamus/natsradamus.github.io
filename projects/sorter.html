Overview

Sorter runs silently in your menu bar and moves new files where they belong — by type, instantly, automatically. No rules to write. No cloud involved. No fuss.

Built with a focus on high-fidelity native macOS aesthetics and calm, unobtrusive behavior. Sorter stays out of your way until it's already done its job.

  • Works instantly — files are sorted the moment they land
  • 100% on-device — no cloud, no accounts, no telemetry
  • 80+ file types supported out of the box
  • Zero retroactive moves — only acts on new files
Security note Sorter operates entirely on-device with no network calls, no external dependencies, and no data collection. File paths never leave the machine. Designed with the same privacy-first principles I apply in enterprise endpoint security work.
