Overview

A native macOS app that scores a machine's security posture against 14 endpoint controls, each mapped to the compliance frameworks an enterprise actually answers to. Instead of a wall of raw settings, it turns posture into a single legible score — and shows which controls move it.

The goal was translation: take the language auditors and security teams use and make it readable to the people running the endpoints. Same instinct I bring to support and enablement work — meet people where they are, and make the complex thing checkable.

  • 14 endpoint controls scored against live system state
  • Each control mapped to GLBA, SOX, NIST CSF, and OWASP Top 10
  • Posture rolled up into a single, explainable score
  • Built native to macOS, in the same idiom as the endpoints it audits
Context Built as internal tooling for enterprise endpoint security. Framework mappings and control logic are described here at a high level; specifics are kept generic to respect the environment it was built in.
